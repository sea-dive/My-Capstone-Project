本研究では、プログラミング初学者がコードのエラーに直面した際、自力での解決を促すためのリアルタイムデバッグ支援システムを提案・開発する。従来のAIによるコード生成ツールは、解答をそのまま提示してしまうため、学習者の論理的思考力の向上が妨げられるという課題があった。そこで本システムでは、大言語モデル（LLM）のプロンプトを最適化し、エラーの直接的な答えではなく、ヒントやデバッグの手順を段階的に提示するアルゴリズムを実装した。開発においては、Pythonを用いてフロントエンドおよびバックエンドを構築し、APIを通じてLLMと連携させた。本システムの有効性を検証するため、大学のプログラミング演習を履修する学生20名を対象に比較実験を行った。実験の結果、提案システムを使用したグループは、エラー解決にかかる時間が平均25%短縮され、アンケート調査においても「エラーの根本的な原因を理解しやすくなった」という高い評価を得た。
